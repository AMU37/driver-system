- ج) لا يوجد دخول بدون إنترنت

**4. متى تظهر لك الرحلة المخططة في تطبيقك؟**

- أ) فور تخطيط المشرف لها دائماً
- ب) عند حلّ وقت الإتاحة المختار
- ج) في بداية اليوم

- أ) تستخدم أي رمز

- ج) تواصل مع مشرف النقل

# القسم الرابع: الاختبار النهائي قبل التشغيل الفعلي

قبل اعتماد أي متدرب للعمل الفعلي، تأكد من:

- [ ] أجهزة التدريب لا تحتوي على بيانات التشغيل الفعلية.
- [ ] كل متدرب أكمل **الاختبار العملي** الخاص بدوره بنجاح.
- [ ] كل متدرب أنجز **اختبار العمل بدون إنترنت** بنجاح.
- [ ] لا يوجد متدرب اعتمد دون تغطية حالة **يحتاج تأكيد** و**غير موظف**.
- [ ] قائمة الحضور موقّعة ومؤرشفة.
- [ ] حساب التدريب غير مستخدم في التشغيل الفعلي.
- [ ] تم إبلاغ مسؤول التشغيل بقائمة المعتمدين.
