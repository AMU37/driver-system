## اقرأ هذا أولاً

### لمن هذه الحقيبة

| الفئة | اقرأ بالترتيب | الزمن |
|---|---|---|
| **السائق** | دليل السائق | 45 دقيقة للقراءة + 3 ساعات تدريب |
| **مشرف النقل** | دليل المشرف | 60 دقيقة للقراءة + ساعتان تدريب |
| **مدير النظام** | مدير النظام + الإعدادات في دليل المشرف | ساعتان تدريب |
| **الإدارة العليا** | العرض التنفيذي + الملاحظات | 30 دقيقة |
| **منسق التدريب** | الخطة + الاختبارات | 90 دقيقة |

### قواعد لا تُكسر

1. **لا تُعتمد بيانات التدريب في التشغيل الفعلي.** القاعدة: بيانات تجريبية في التدريب، وبيانات حقيقية في التشغيل فقط.
2. **لا يبدأ متدرب دون اجتياز الاختبار العملي.** القراءة لا تعني القدرة.
3. **لا يعمل متدرب مع الطواقم الفعلية قبل اعتماده من المدرّب.**
4. **كل تعديل مستقبلي على التطبيق يستلزم مراجعة الأدلة والاختبارات.**

## المسار الموصى به

### للسائق الجديد

```
دليل السائق  ←  جلسة الجهاز والدخول  ←  جلسة الرحلة والتوثيق
   ←  جلسة العمل بدون إنترنت  ←  الاختبارات 1 إلى 4  ←  اعتماد
```

### لمشرف النقل الجديد

```
دليل المشرف  ←  جلسة التخطيط  ←  جلسة البيانات والتقارير
   ←  الاختبارات 5 إلى 7  ←  اعتماد
```

### للتشغيل الأول في المنشأة

```
حسم الموانع الثلاثة  ←  تجهيز البيانات المرجعية  ←  تدريب المشرفين
   ←  تدريب السائقين  ←  تشغيل تدريبي لأسبوع  ←  تشغيل كامل
```

## قائمة التحقق قبل التشغيل الفعلي

### البيانات

- [ ] استُوردت قائمة الموظفين كاملة من ملف معتمد.
- [ ] روجعت عينة من الصفوف المرفوضة.
- [ ] أُنشئت الشركات والإدارات والوظائف والسكن.
- [ ] ضُبطت الشركة على كل باص وخط.
- [ ] تحققت من أن كل سائق مرتبط بشركته.

### الحسابات

- [ ] حساب لكل مشرف نقل، وكل حساب بمدير النظام منفصل.
- [ ] حساب لكل سائق، باسم مستخدم فريد.
- [ ] غُيّرت كل كلمات المرور المؤقتة.
- [ ] فُصلت حسابات التدريب عن حسابات التشغيل.

### الأجهزة

- [ ] اكتملت المزامنة الأولى على كل جهاز سائق.
- [ ] ضُبط الرمز المحلي لكل سائق.
- [ ] تغيّر رمز الدخول المحلي لجهاز المشرف.
- [ ] شحنت البطاريات.

### التدريب

- [ ] أكمل كل سائق الاختبارات 1 إلى 4.
- [ ] أكمل كل مشرف الاختبارات 5 إلى 7.
- [ ] سُجّلت القوائم وقُيّمت النتائج.
- [ ] أبلغ مسؤول التشغيل بقائمة المعتمدين.

### التشغيل

- [ ] حُسمت موانع النشر الثلاثة.
- [ ] جُرّب ربط التقارير مع Microsoft.
- [ ] جُرّب إرسال رحلة تجريبية كاملة ووصلت للتقرير.
- [ ] حدُّد تاريخ بدء التشغيل التدريبي.

## مؤشرات المتابعة بعد التشغيل

| المؤشر | القيمة المطلوبة |
|---|---|
| رحلات موثّقة مقابل مخططة | 95% فأعلى |
| رحلات لم تصل للنظام | صفر |
| طلبات موظفين معلّقة | صفر بنهاية اليوم |
| عناصر محلية غير مُرسلة | صفر قبل مغادرة الجهاز |
| موظفون بعلامة «يحتاج تأكيد» | تناقص شهري |

## ملاحظات للمنسق

- **حدّث الوثائق عند تعديل التطبيق.** أي زر جديد يحتاج سطراً في الدليل وسؤالاً في الاختبار.
- **طبّع.","** الأدلة قبل الطباعة. لا تطبع من نسخة قديمة.
- **احفظ قوائم الحضور.** هي إثبات اعتماد.
- **راجع طلبات الموظفين الجدد أسبوعياً.** تراكم الطلبات مؤشر على خلل في التدريب.
- **افصل بيانات التدريب تماماً** عن بيئة التشغيل، ولا تسمح باختبار على بيانات حقيقية.
